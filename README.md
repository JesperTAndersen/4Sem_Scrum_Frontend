# scrum-frontend

## Kom i gang

1. Node 22 (`nvm use`)
2. `npm ci`
3. Kopiér `.env.example` til `.env`
4. Start Java-backenden på port 8080
5. `npm run dev`

## Scripts

- `npm run lint` / `npm run lint:fix`
- `npm run format`
- `npm run build`

## Konventioner

- Feature-mapper under `src/features/`
- Imports med `@/` i stedet for relative stier
- Branch: `feature/kort-beskrivelse`, PR med én reviewer
